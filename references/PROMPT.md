# 给编导或语言模型的策划提示词

将下方整段复制给编导或语言模型，填写方括号，并附上复用包。这份长指令用来规划制作；ComfyUI 图像和视频节点使用 [COMFYUI_PROMPTS.md](COMFYUI_PROMPTS.md) 中的短描述。使用支持本技能的环境时，可以在开头加上 `$nasa-archive-explainer`。

```text
请按“复古技术档案 × 动态图解科普”风格完成以下视频任务。
团队用 ComfyUI，题材主要是工程与数学；NASA 视频仅为视觉参考。

【选题】
主题：[填写]
知识类别：[工程 / 数学 / 物理 / 计算机 / 技术史 / 其他]
核心问题：[填写，尽量只有一个中心问题]
观众：[填写；未指定时按有好奇心的普通中文观众]
目标时长：[填写；未指定时先按 3–5 分钟组织文案]
最终希望观众理解：[填写一句结论]
已有资料、文件和来源：[填写]
本次交付范围：[文案 / 文案与分镜 / 带配音样段 / 完整影片]
配音与画幅要求：[填写；未指定画幅时用 16:9]
其他必须保留或避免的内容：[填写]
已有 ComfyUI 版本、模型与基础工作流：[填写；未知记未确定]
已有配音、字幕、合成节点或工具：[填写；未知记未确定]

【风格定义】
像在桌面上翻阅技术手册与研究笔记：
真实资料、数学定义和已知条件提供依据，
工程手册、网格纸、照片、图形和纸签组织信息，
少量红色圈注、细线和编号定位重点，
通过比较、拆解、测量、替换、连接和运行把因果讲清楚。
纸面与深色桌面按内容交替，保留叠纸、照片边缘和适度阴影。
整片要有档案材料与实物的层次，避免只做统一浅色幻灯片。
数学画面以研究纸面、坐标系、几何和分步推导为主；
不用强塞火箭、NASA 标志、金属设备或虚构历史背景。

【题材适配】
先说明本题的对象、变化、关系与结论。
工程适合结构、传动、受力、流动、反馈、制造和设计取舍。
数学适合几何、函数、微积分直觉、矩阵、概率与算法过程。
长证明和高维抽象题需另行分步，明确示意范围、假设与推导；
不把类比当证明，不为短视频节奏省略必要条件。

【叙事与文案】
从具体物件、现象、图形、故障或操作切入，让观众产生一个问题。
只补充理解这个问题所需的背景。
用必要的证据和机制逐步回答，按题材设置转折或限制。
结尾回到开头的物件，让观众能用一句话复述结论。
不固定章节数量，不机械照搬参考片顺序。
历史题可用年代线，工程可用需求与约束线，
数学可用问题、构造、变换、推导和结论线，不强行套历史叙事。
旁白冷静、好奇、口语化；短句推进因果，长短句与停顿自然变化。
技术词先解释作用，数字用于比较，日期用于理清事件关系。
重新组织事实与措辞，不逐句替换参考片的同义词。
真实事件、技术参数、引文和时间顺序以可靠来源核实；
资料有冲突或缺口就明确记录，不能用戏剧化叙述补成事实。
工程核对结构、方向、单位和简化；
数学核对条件、符号、坐标尺度、曲线计算和推导。

【ComfyUI 制作分工】
A. 生成式素材：纸面、对象外观、材料和环境。
B. 图生视频：允许变化的展示及非关键镜头移动。
C. 精确图层：公式、曲线、坐标、受力箭头、尺寸、单位和文字。
D. 合成与时间轴：导入图层或帧序列，按实际录音安排动作，
   再完成字幕、配音、拼接和导出。
关键知识图层不默认经过扩散重绘或生成式补帧。
固定种子不能作为结构、公式或视频时序准确的证明。
分别输出策划指令、图像正向、可选负向、视频动作描述与精确图层任务。
只对已确认存在的模型和节点给可执行连接与参数；
未知环境提供路线与依赖清单，写待环境核实，不编造接口或宣称跑通。
不要让同事把整份策划指令直接粘到文本编码节点。

【视觉参数】
默认 1920×1080、30fps；目标平台另有要求时重新布局。
纸面 #ECE5D6；深墨与桌面 #25251F；次要字 #5A594F；
网格 #C8C3B7；重点红 #D63A2C。
窄幅彩条可用 #4C5A68 / #7A7F4E / #D2A85E / #A8432F。
这些是团队复现参数，不宣称为参考作者原始工程数值。
中文用 Noto Sans SC，英文标题用 Archivo，编号用 Space Mono。
真实标志用可靠矢量或图片，保持几何，不用字体猜画。
新绘设备先明确底材与模块结构，再按用途添加功能图案、
编号和方向标签、身份标记、关键操作强调色与局部使用痕迹。
这些要有功能依据，不堆伪文字和无意义管线；
历史对象按真实资料呈现，不凭空添加结构或损坏。
标题、对象标注、结论和字幕分区；重要文字在目标设备上易读。
纸纹轻微、静止即可，不能损伤字形和设备细节。
历史图像负责证据，自绘图解负责机制；两者身份明确。
生成画面不得伪装成档案照片或真实技术图纸。
新题材按资料更换对象，不强行加入 NASA 标志或火箭。

【每个镜头怎样设计】
先将旁白拆成对象、动作、关系、结论。
每个信息节拍记录：
1. 台词中的词或短语锚点；
2. 画面里的具体对象；
3. 对象发生的可见变化；
4. 该变化让观众理解的事实；
5. 动作完成后的阅读停留；
6. 素材来源与未解决问题。
同时记录该节拍的 ComfyUI 路线与另做的精确图层。
讲不匹配就叠合比较，讲装配就逐步接合，
讲尺度就让标尺与比较关系变化，讲流动就展示正确方向。
保留同一对象的连续性，让观众看清前后关系。
整图缩放、字幕替换、颗粒闪动不能独立完成解释。
标注和引线跟随对象及镜头变换，避免悬空或指错位置。
功能示意需明确，不把简图长度或粒子数量当作真实数据。

【录音与时间轴】
制作影片时，以最终实际配音为时间基准。
用实测词或短语时间戳驱动画面、字幕、标注与音效。
记录时间单位、片段起点及偏移，修改录音后重新校准。
源帧率、目标帧率与录音时长分别记录。
尚未录音或没找到锚点时写“待校准”，不伪造精确秒数，
不把总时长平均分给图片，也不用旧稿时间轴套新稿。
配音清楚克制、留有读图停顿；无需复制参考作者声纹。
音乐低于旁白，音效跟随有意义的动作，不强行为音乐卡点改台词。

【执行与交付】
按本次交付范围完成工作；只要文案时不自行制作全片。
若要求制作影片，先完成一小段覆盖核心讲解动作的样段，
检查关键词附近的连续帧，并按正常速度完整听看，
修正后继续全片。内部验证不增加用户未要求的批准环节。
完整影片交付可播放视频、可编辑工程、旁白、素材来源、
统一时间轴与检查记录；另附 ComfyUI 画布 JSON、输入素材、
模型和节点版本，按需附 API 图。配音和合成环节明确所用节点或工具。
检查字体覆盖、文字准确性、布局、比例、动作含义与声音。
必需素材和字体缺失时标明阻塞，不宣称成片可交付。
任何没运行、无接口或仍待人工复核的检查均如实记录；
截图、运动量或自动检查不能替代正常速度完整听看。

若附有复用包，优先阅读 STYLE_GUIDE、分镜模板与参考图，
使用 CHECKLIST 记录实际进度，按 COMFYUI_GUIDE 安排各环节。
不要把这份风格提示词理解为任意主题都已存在的一键渲染程序。
```
