# 这种风格适合什么主题

## 风格与题材的关系

风格名为“复古技术档案 × 动态图解科普”。NASA 视频提供的是纸面、照片拼贴、网格、编号、克制红色与逐层分析的方法；新片可以完全没有航天内容。

最适合的问题具备至少一种可见关系：结构、尺寸、方向、数量、比例、路径、前后状态或因果变化。观众可以跟着画面看出“哪里变了，因此发生了什么”。

“复古”是一套美术和信息组织方法，不要求虚构老照片、历史手稿或旧时代人物。数学题可以像研究笔记，工程题可以像拆读技术手册。

## 工程类：优先适用

| 方向 | 可用选题 | 主要解释动作 | 必须精确的部分 |
| --- | --- | --- | --- |
| 机械与传动 | 齿轮为什么能变速；差速器怎样工作 | 剖开、啮合、旋转，对照输入与输出 | 齿数、转向、传动关系、接触位置 |
| 土木与结构 | 三角桁架如何分担载荷；拱的力往哪里走 | 加载、分解、传递，比较结构变化 | 支撑条件、受力方向、几何与简化假设 |
| 电路与控制 | 反馈为什么能纠偏；滤波器保留了什么 | 信号通过模块，误差变化，对照输入输出 | 接线、极性、信号和时间尺度 |
| 流体与热学 | 换热器如何工作；液压怎样传递作用 | 展开通道，按正确方向流动，标注状态 | 边界条件、方向、守恒关系和单位 |
| 材料与制造 | 同样的金属怎样形成不同结构；增材与切削 | 截面、层次、逐层加工与材料去除 | 微观结构身份、尺寸尺度、工艺顺序 |
| 工程取舍 | 轻量化为什么会带来新限制；冗余的代价 | 对照方案，改变参数，展示约束 | 数据出处、量纲、评价指标与适用范围 |

生成模型可制作有统一材质的机械对象、环境和气氛；只要结构参与推理，关键轮廓、零件关系和运动仍需计算、核实或精确图解。外观合理不等于机制正确。

## 数学类：优先适用可视化主题

| 方向 | 可用选题 | 主要解释动作 | 必须精确的部分 |
| --- | --- | --- | --- |
| 几何与测量 | 相似关系怎样帮助测量；面积为什么能重排 | 对齐、分割、平移、重组、测量 | 长度、角度、对应关系、面积保持 |
| 微积分直觉 | 割线怎样趋近切线；积分怎样累积 | 两点靠近、局部放大、条带细分与累积 | 函数、采样位置、极限条件与坐标尺度 |
| 线性代数 | 矩阵怎样改变平面；行列式怎样描述面积变化 | 网格和基向量一起变换，对照前后面积 | 矩阵作用、方向、比例、符号 |
| 概率与统计 | 条件改变后样本空间发生什么；抽样为何有波动 | 分组、筛选、计数，多次抽样对照 | 样本空间、概率权重、随机过程和分母 |
| 波与傅里叶 | 复杂波形怎样由不同频率叠加 | 逐项加波，保持同一时间轴对比结果 | 频率、振幅、相位和计算得到的合成波 |
| 图论与优化 | 路径怎样被逐步找到；约束怎样缩小可行域 | 节点连边、逐步搜索、移动边界 | 算法步骤、权重、约束和有效解 |

数学视觉以研究纸面、坐标系、色块、几何对象和简洁公式为主体。不能每题都加金属设备、航天徽章或维修痕迹。抽象概念的类比应注明条件，图形直觉不能代替尚未给出的证明。

## 也适合的相邻题材

- **物理机制**：光路、振动、杠杆、能量转换；使用真实模型和必要的理想化条件。
- **计算机原理**：缓存、编码、数据流、算法过程；对象可以是数据块和状态，不必伪装成实体机械。
- **技术与设计史**：从实物细节和资料解释某项标准、设计或工艺为什么出现。
- **有明确数量机制的其他知识**：先建立可检查的对象和关系，再决定用多少档案素材。

这是制作适配建议，不是限制用户选题的分类规定。

## 需要改编后使用

| 情况 | 怎样调整 |
| --- | --- |
| 长篇代数推导、形式证明 | 分清假设、推理步骤和结论；增加可编辑公式层和分步停留，减少照片拼贴 |
| 高维、无法直观成像的概念 | 明确投影或低维示例的范围，再用符号与推导补足；不把简图当作完整对象 |
| 主要依靠精细模拟的数据结论 | 先取得计算或实验结果，再用风格化排版展示，不用生成视频伪装模拟 |
| 抽象哲学、观点漫谈或情绪叙事 | 先判断是否有可视化的证据关系；若没有，本风格只能提供外观，不能自动建立解释 |
| 需要完整课堂推导的长课 | 划分问题和推导段落，保持每步可读；不为短视频节奏省掉关键条件 |

## 30 秒选题判断

开工前写出四句话：

1. **对象是什么？** 可以是零件、梁、波形、矩阵、点集、样本或状态。
2. **什么发生变化？** 位置、结构、尺度、连接、数量、参数或条件。
3. **变化说明什么关系？** 因果、比例、约束、守恒、映射或推理。
4. **哪些必须精确？** 公式、方向、单位、形状、计数、结果和条件。

四句明确，就能进入分镜。若只写出“旧纸、红字、很有科技感”，还没有建立适合这种视频的解释结构。

## 同风格、不同主题的三种开场

- 工程：“把这根杆拿掉，同一副结构发生了什么？”画面保持支撑条件一致，对照结构与载荷路径。
- 数学：“同一张网格，被一个矩阵变换后，面积变了多少？”画面保留前后尺度，逐步展示基向量与区域变化。
- 计算机：“这条请求为什么先经过缓存？”画面沿同一条请求路径展示状态，而非用无关机房照片代替流程。

这些是选题与分镜示例，不是已经核实、配音和制作的成片脚本。
