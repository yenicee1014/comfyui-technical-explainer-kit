# ComfyUI 制作说明

## 结论与证据范围

**这种风格可以用于 ComfyUI 制作；完整影片需要素材、精确图解、时间轴、声音和合成共同完成。** 一份风格文档不会自动变成节点图，一段提示词也不保证输出原片的讲解动作。

本包包含两条已运行的路线：原来的 2 秒无声数学合成，以及新增的[游标卡尺带声完整案例](../examples/vernier-caliper/README.md)。后者由精确动画输入、ComfyUI 分段合成、FFmpeg 拼接和 ComfyUI 整片导出共同完成。新手先读[首页教程](../README.md)，技术证据见[验证记录](COMFYUI_VERIFICATION.md)。生成模型的材质、场景与图生视频路径参考官方工作流，但没有在这两次制作中加载模型；同事的模型与节点组合仍需在自己的机器上试样段。

## 各类文件放在哪里

| 内容 | 接收方 / 用法 |
| --- | --- |
| `PROMPT.md` 的整段制作指令 | 编导或语言模型，用于文案和镜头规划 |
| `COMFYUI_PROMPTS.md` 的正向图像描述 | 已有图像工作流的文本编码节点 |
| 可用的负向描述 | 仅放入支持且实际启用负向条件的对应节点 |
| 图生视频动作描述 | 现有视频工作流的文本条件节点，具体依模型而定 |
| `precision-composite.json` | 拖入 ComfyUI 画布的验证工作流 |
| `precision-composite-api.json` | 用 `/prompt` 提交的 API 节点图，不当作普通画布文件 |
| 数学公式、坐标图、受力箭头、字幕 | 由计算或排版生成的图层 / 帧序列，再进行合成 |

不要把 `SKILL.md` 当作 ComfyUI 插件安装。字体文件也不是模型；它们由排版或绘图环节加载。

## 推荐的生产分工

### A. 风格素材与关键帧

用团队已经跑通的图像工作流制作纸面、空白技术板、物件、剖面外观和场景。记录模型文件、版本、尺寸、采样器与种子。优先统一同一片中的对象、材质、视角和光线。

参考图、结构条件或局部重绘可按现有模型能力使用；相应适配器、ControlNet 或自定义节点需要额外兼容性检查，不预设每台电脑都有。固定种子方便复现同一设置，不保证换镜头、换模型或连续视频时形状不漂移。

生成图像的尺寸依模型与显存设置；最终成片可另行排版到 1080p。不要为追求导出分辨率而盲目把生成参数设成 1920×1080。

### B. 允许变化的运动镜头

使用团队现有图生视频模板，让实物展示、材质、非关键环境和适度镜头移动连贯起来。官方 Wan2.2 文档提供 I2V 和首尾帧等路线，可作为能力与模型配置的参照；它不构成本包对同事现有显卡、模型或输出准确性的保证。

动作提示词写清“谁动、怎样动、谁保持不变、镜头怎么走”。尽量先验证一个主动作。关键几何、公式和字幕预留合成位置。

首尾帧控制两端状态，也不能单独证明中间运动正确。每段检查首、中、尾及转折附近连续帧。

### C. 精确知识图层

以下内容以可计算、可核查的方式生成：

- 数学公式、坐标轴、函数曲线、矩阵变换、面积分割、计数和概率权重。
- 受力箭头、电路连线、流动方向、尺寸线、单位、测量基准与技术标签。
- 标题、字幕、年份、数据与机构字标。

可由团队已有的计算、排版或图形节点生成，也可以先制作 PNG 透明图层、逐帧图像或动画图像后导入 ComfyUI。本包实测的是“导入预先计算的图层”路线，不要求同事先写代码。

核心 `LoadImage` 在本次版本中可读取随包的动画 WebP 帧。`ImageCompositeMasked` 将图层按蒙版合成。`LoadImage` 的 MASK 对透明区域取较高值，因此把其输出作为不透明度使用时，需要 `InvertMask`；不能凭黑白预览猜方向。

批次帧数与画布尺寸要匹配。原数学验证先将背景复制 48 次，再与 48 帧图解合成；卡尺案例按每个短批次的真实帧数复制背景，每段最多 60 帧。否则本次版本的合成逻辑可能只按背景批次数保留源图层。

### D. 声音、字幕与时间轴

实际录音决定时间轴；镜头帧率决定每个时间点对应哪一帧。记录源帧率、目标帧率、录音锚点与段落偏移，不能只把视频延长到某个总时长就算同步。

配音可从团队现有声音节点或录音文件取得。字幕与标注按实际词或短语排入时间轴，先验证核心解释样段。

合成输出可使用团队已有视频节点；原无声验证使用 `SaveWEBM`，卡尺案例使用核心 `LoadAudio → CreateVideo → SaveVideo` 加入声音并导出 MP4。团队若用 VideoHelperSuite 等社区节点，按实际安装版本与接口连接；本包不捆绑或宣称已实测这些第三方节点。

配音、字幕、镜头拼接与混音需指定明确节点或已有合成工具。卡尺案例的配音由 macOS `say` 生成，字幕预绘制在透明图层里，FFmpeg 负责拼接，ComfyUI 负责合成与导出；并未把这些步骤宣称为一个节点图自动完成。只有原六节点验证工作流，还不能完成声音与整片。若要求全部留在 ComfyUI 内，先将对应节点和依赖补进项目清单；不悄悄换成浏览器动画工程。

## 直接运行随包的验证

1. 将 `comfyui/input/paper.png` 和 `projection.webp` 上传到你的 ComfyUI 输入目录。
2. 将 [precision-composite.json](../comfyui/precision-composite.json) 拖入画布。
3. 在两个 `LoadImage` 节点中确认对应文件。
4. 确认核心节点 `RepeatImageBatch`、`InvertMask`、`ImageCompositeMasked`、`SaveWEBM` 可用；缺失时先核对 ComfyUI 版本与节点导入状态。
5. 运行。输出是一段 640×360、24fps、2 秒的无声几何投影验证视频，保存在 ComfyUI 的输出目录。

验证输入随包提供，运行工作流不需要扩散模型、API Key、付费接口或 Python 脚本。`make_demo_inputs.py` 仅用于需要修改或重建演示输入的情况，依赖 Pillow 和随包字体。

这一小段只证明精确图层能够在本次 ComfyUI 节点链路中合成并导出，不证明任何生成模型能按相同精度画对电路、公式或机械运动。

## 新项目如何选路线

| 镜头任务 | 建议路线 |
| --- | --- |
| 纸面、物件外观、环境和材质 | 文生图 / 图生图，按已有模型配置 |
| 非关键镜头移动和物件展示 | 图生视频，检查形状和细节稳定性 |
| 齿轮啮合、力学变化、电路拓扑 | 核实结构或确定性动画，再风格化合成 |
| 函数、公式、统计和矩阵 | 计算绘图 / 公式排版 / 精确动画，合成后保留准确性 |
| 标题、标签、字幕与度量 | 可编辑文本或精确图层，按录音时间显示 |
| 全片时间轴与混音 | 团队明确选定的视频、字幕和音频节点或合成工具 |

关键知识图层合成后，不再默认经过扩散重绘或生成式补帧；若确有需要，重新逐帧检查准确性。

## 跨电脑交接清单

除本包外，每个制作项目需交付：画布 JSON、必要时的 API 图、输入素材、模型文件名与来源、节点版本、字体、录音、实测时间轴、成片与检查记录。模型权重按合法来源单独获取，不把个人目录、凭证或 API Key 写进共享工作流。
